# Documentation Archive

This folder contains planning notes, audits, exploration, and historical decision logs from earlier phases of the Musifer site project.

## Contents

- **planning/** — Planning and strategy documents (infrastructure, analytics, domain rollout, responsive layout roadmap, etc.)
- **audits/** — CSS audits, CMS audits, SEO audits, and decision-log audits from development phases
- **working/** — Work-in-progress exploration (soundcloud-wrapper, visual-update, FB migration, etc.)
- **issues/** — Historical issue logs and deferred feedback

## Usage

These documents are retained for:
- **Historical reference** — Understanding why past decisions were made
- **Rollback/revert** — If a future direction needs to reference old plans
- **Context** — Onboarding team members or reviewing project evolution

They are **not** part of the active development workflow. Current operational docs live at the root of `docs/`:
- `docs/cms-content-spec.md` — CMS model and fields (active)
- `docs/sitemap.md` — Current information architecture (active)
- `docs/workflows/two-device-development-routine.md` — Day-to-day dev workflow (active)

For new planning, decisions, or work items, use GitHub Issues and GitHub Project instead of creating new markdown in docs/.
